  CURRENT WORKING DIRECTORY only; the generated env lives at `$ACE_CONFIG_DIR/runtime/.env`. In a

  is exactly the class of defect the release notes' F5–F10 caveat gestures at: pip-only path not
  fully wired.)

  From there: PASS configuration / PASS surrealdb ws://localhost:18122 / PASS schema 179

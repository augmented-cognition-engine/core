## Product contract proved

ACE 0.7.0 is the first public foundation for ACE as an open, self-hosted Intelligence Operating
System. Its first product experience is the Intelligence Builder:

```text
Connect -> Map -> Watch -> Brief -> Activate
```

The bounded provider-free journey proposes exact source scope, creates a cited and editable
concept model, proposes approved monitors, produces a cited first Brief, compiles approved material
through the stable Domain Pack contract, presents exact effect and permission scope, activates one
versioned revision, and preserves exact receipts through restart. Generated pack material receives
no special trust: compatibility, conformance, authority, preview, approval, and activation remain
fail-closed.

The same public package composes Agent Composition AC1-AC7 and authorized Agent Memory AM0-AM3.
Composition policy admission requires independent review and current authority; memory ingestion,
correction reconciliation, recall, and Context Manifest consumption preserve their content-free
receipt and authorization boundaries. Schema head remains v177. The thin public MCP surface remains
exactly eleven tools.

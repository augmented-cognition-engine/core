# ACE evidence archive

This directory preserves point-in-time acceptance, release, and roadmap evidence. These records
support auditability, but their branch names, test totals, pending checks, and next-work statements
describe the moment they were written. For current product support use
[capability maturity](../capability-maturity.md); for current outcome state use the
[public roadmap](../../ROADMAP.md).

Status labels below are literal: **public** means the referenced artifact (tag, GitHub Release, or
PyPI package) exists and is independently re-derivable; **candidate** means local implementation
and evidence exist but publication is pending; **historical** means the record predates and is
superseded by later work and is kept for audit trail only.

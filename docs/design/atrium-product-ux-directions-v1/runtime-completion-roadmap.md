# ACE interface direction — runtime completion roadmap

Controlling product input: `ACE_Product_Interface_Direction_v1.docx` (11/11 pages reviewed)

Superseded working title: **ACE Core 1.1.0 — Living Intelligence Interface**. This UX track is not an independent release authority and will not tag or publish that title.

Integration target: selected UX/runtime slices are candidates for the official **ACE 1.1 Code Intelligence** integrated candidate, subject to control-tower reconciliation and acceptance. Passing in this separate worktree is evidence for handoff, not integrated release acceptance.

The brief-aligned interface is complete at the current public contract ceiling. This roadmap tracks the runtime/public-contract work required to turn explicit `unsupported`, `contract only`, and `not exposed` states into usable capabilities without weakening ACE’s authority, provenance, or product boundaries.

## Non-negotiable invariants

- Existing RAG/search semantics remain unchanged.
- No second activation, Pack, correction, connector, graph, agent, subscription, or handoff framework.
- A consumer subscription is not a provider API credential.
- Counts, record presence, page time, or UI state never substitute for coverage, confidence, freshness, resolution, or health.
- Historical material is immutable; correction, upgrade, and rollback create new attributed revisions.
- Custom Intelligence remains proposal-only Preview in v1.
- World and Market may execute only through current authority, admitted source capability, and exact runtime support.
